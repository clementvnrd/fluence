# Audit — October 2026

Full audit of both apps against the three priorities: **data protection, transcription
reliability, robustness**. Every defect below was found by reading the code and the
P0/P1 items were re-checked by hand. Severity: P0 = the feature does not work, P1 = data
leak or lost dictation in normal use, P2 = lost/wrong output in a plausible edge case,
P3 = minor.

Linear tracks the work; this file is the record. Issue keys are listed in §6.

---

## 1. Verdict

| | macOS | Windows |
|---|---|---|
| Works end to end | Yes, in daily use | **No — never transcribes** (§2.1) |
| Data protection | Weak: plaintext history forever, transcripts in the unified log, clipboard leaks | Plaintext history, otherwise clean (no network, no text in logs) |
| Transcription reliability | Clips first and last words, no VAD, no device-change handling | Same, plus 20 ms-energy segmenter cutting inside words |
| Robustness | One real race on fast re-press; stuck-key = open mic | Slow work inside the keyboard hook; stuck-key = open mic |
| Docs | README badly stale | Several claims contradicted by the code |

The architecture is good — the problems are fixable without redesign. The engineering
discipline (shared test vectors, strict analyzers, logic-free platform layer, buffers
copied before hand-off, HUD that never takes focus) is above the usual standard for a
project this size.

## 3. What is done well

- **Cross-platform contract**: `shared/dictionary-test-vectors.json` run by both test suites, drift guarded in CI.
- **Windows build discipline**: warnings-as-errors, `--no-incremental`, `CA1416` used as an architecture fence, platform layer kept logic-free, 63 tests incl. headless UI.
- **Audio correctness basics**: buffers copied before hand-off on both sides; single ordered drain task instead of a task per buffer; bounded channel that never blocks the audio thread.
- **Focus safety**: non-activating HUD that can never take key status; AX insert verified by caret movement before falling back.
- **Windows input**: Right Ctrl default (AltGr-safe), observe-don't-swallow hook, Unicode `SendInput` that never splits surrogate pairs, injected events tagged so they cannot re-trigger.
- **LLM cleanup has guard rails**: low temperature, timeout, plausibility check, rule-based fallback, "answered the question instead of transcribing" detection.
- **Dictionary**: whole-word fences, NFC normalisation, `CultureInvariant`, literal replacement, regex timeout, warnings for risky entries, history shows which corrections fired.
- **No network code** apart from model download; Wispr Flow's database opened strictly read-only.
- **Stable code signing** so TCC grants survive rebuilds — and the reasoning is documented.

## 5. Gap to Wispr Flow (October 2026)

Wispr Flow processes **everything in the cloud** (dictation and Notetaker). Its own docs
list no offline dictation, and Notetaker transcription is server-side; a HIPAA BAA disables
Notetaker entirely. A fully local equivalent is the differentiator, not a compromise.

| Wispr Flow feature | Here |
|---|---|
| Push-to-talk, **hands-free toggle** (double-tap / key+Space), **Esc cancel**, paste/copy last transcript | PTT only |
| Cleanup levels (None/Light/Medium/High), self-corrections, lists | One on/off LLM pass (macOS only), English-only fillers |
| **Styles per app category** (personal / work / email / other), from the active app or URL | None |
| **Context awareness** (text near the caret, app name, URL) | None |
| **Command Mode** (edit selection by voice) | None |
| Dictionary with **auto-learn from user edits**, starring | Manual dictionary, Apple engine biasing only; Parakeet gets no biasing (FluidAudio has `CustomVocabularyContext`) |
| **Snippets** (voice shortcuts, rich text) | None |
| 100+ languages, auto-detect, language picker | Apple: `Locale.current` only; Parakeet v3: 25 EU languages auto; cleanup prompt English-only |
| History with audio playback (14 d), recovery after crash | Text history, no audio |
| Scratchpad, mouse-button hotkeys, pause in banking apps | None |
| **Notetaker** | None — see `docs/NOTETAKER.md` |
