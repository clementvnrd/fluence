# Fluence 0.2.4

## Français

Un moteur cloud en option pour une dictée bien plus juste. Si Fluence 0.2.x est déjà installé, il propose cette version de lui-même : cliquez sur « Installer ».

**Nouveau**
- **Moteur cloud ElevenLabs (Scribe v3), en option.** Réglages › Transcription › « Moteur cloud ». Il est coupé par défaut et marche avec votre propre clé ElevenLabs, gardée dans le Trousseau. « Tester » vérifie la clé (FLU-113).
  - Mesuré sur 554 enregistrements en français : environ 2 % de mots faux sur des phrases lues contre 6,7 % pour Parakeet, et 4,6 % contre 20,7 % sur le franglais.
  - Votre dictionnaire est envoyé comme vocabulaire avec chaque dictée.
  - Parakeet transcrit en parallèle sur le Mac. Si ElevenLabs tarde, est hors ligne ou refuse la clé, c'est le texte de Parakeet qui est tapé, et la capsule dit pourquoi (« Hors ligne », « Clé refusée », « Cloud trop lent »). Une dictée n'est jamais perdue.

**À savoir**
- Avec le moteur cloud activé, l'audio de chaque dictée, sa langue et les termes de votre dictionnaire partent chez ElevenLabs (serveurs aux États-Unis par défaut), avec votre clé. Le nettoyage du texte reste sur le Mac. Coupé, rien ne change : aucun texte, aucun son, aucun nom ne quitte le Mac.
- Signée mais **pas notarisée** par Apple : une première copie téléchargée demande Réglages Système › Confidentialité et sécurité › *Ouvrir quand même*. Une mise à jour depuis la 0.2.x n'en a pas besoin.
- Pour Mac avec puce Apple (M1 ou plus récent), macOS 26 ou plus récent.

## English

An optional cloud engine for much more accurate dictation. A copy of Fluence 0.2.x offers this version by itself: click « Installer ».

**New**
- **Optional ElevenLabs cloud engine (Scribe v3).** Réglages › Transcription › « Moteur cloud ». It is off by default and works with your own ElevenLabs key, kept in the Keychain. « Tester » checks the key (FLU-113).
  - Measured on 554 French recordings: about 2 % wrong words on read sentences against 6.7 % for Parakeet, and 4.6 % against 20.7 % on franglais.
  - Your dictionary is sent as vocabulary with each dictation.
  - Parakeet transcribes on the Mac at the same time. If ElevenLabs is slow, offline or refuses the key, Parakeet's text is typed, and the capsule says why (« Hors ligne », « Clé refusée », « Cloud trop lent »). A dictation is never lost.

**Good to know**
- With the cloud engine on, each dictation's audio, its language and your dictionary's terms go to ElevenLabs (US servers by default), with your key. Text cleanup stays on the Mac. Off, nothing changes: no text, audio or name leaves the Mac.
- Signed but **not notarized** by Apple: a first downloaded copy needs System Settings › Privacy & Security › *Open Anyway*. An update from 0.2.x does not.
- For a Mac with Apple silicon (M1 or newer), macOS 26 or newer.
